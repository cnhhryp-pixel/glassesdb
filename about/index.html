About GlassesDB

A database first.
An opinion site second.

GlassesDB is built to make a fast-moving product category easier to understand and compare.

Methodology

We normalize core specifications into consistent fields such as category, display, camera, audio, AI, weight and compatibility. When a specification cannot be confirmed, we prefer “unavailable,” “varies,” or an approximate label over a fabricated number.

Sources

Primary product data should come from manufacturer product pages, official documentation and support material. Each database entry includes an official-source link and a verification period so readers can re-check fast-changing details.

What the database does not assume

  • Marketing terms from different brands are not treated as identical technical categories.
  • Regional AI availability is not assumed to be universal.
  • Prescription support is not assumed from frame shape alone.
  • Compatibility is described by the actual connection requirement when possible.

Updates & revisions

Major database and methodology changes are recorded in the GlassesDB change log.

Corrections & contact

Found a specification that has changed or a model we should track? Send the correction with an official manufacturer source to cnhhryp@gmail.com.
