Data transparency

Data quality dashboard

Completeness measures how many key specification fields have been verified and populated. It is a coverage metric, not a product rating or recommendation score.

How it worksKey fields include category, display, camera, audio, AI, weight, compatibility and relevant hardware fields such as resolution, field of view, refresh rate, brightness, battery, storage, wireless, IP rating and prescription support. Fields that do not apply to a category are excluded.

Why some products stay below 60%

Some manufacturers do not publish the same depth of technical data for every model. GlassesDB leaves those fields blank instead of filling them from uncertain secondary sources just to raise the score.

How records improve

When manufacturers publish new documentation, support pages or technical specifications, the shared data layer is updated and completeness recalculates automatically.
